# Andres Aramburo — Portfolio

Personal portfolio site for Andres Aramburo, a Software Solutions Engineer & Designer with 5 years building enterprise platforms, 3D tools, mobile apps, and design systems. Built with a Linear.app-inspired aesthetic — dark, minimal, and fast.

**Live site:** [earamburo.github.io](https://earamburo.github.io)

---

## Highlights

- **Hero** — Two-column layout with an auto-advancing project carousel, live stats, and a downloadable resume
- **Projects** — Draggable horizontal carousel showcasing featured work including a Chrome extension, enterprise rebrands, and mobile prototypes
- **Experience** — Interactive horizontal timeline with clickable nodes and animated detail panels for each role
- **Tech Stack** — Grouped skill tags across Core Stack, Design & 3D, and Tools
- **Contact modal** — "Start a project" form that pre-fills a mailto with the client's name, email, and project brief

## Tech Stack

| Layer | Tools |
|---|---|
| Framework | React 18 + TypeScript |
| Build | Vite |
| Styling | Custom CSS design system (scoped, Linear-inspired) + Tailwind CSS |
| Routing | React Router v6 |
| UI primitives | shadcn/ui |
| Deployment | GitHub Pages |

## Local Development

```bash
npm install
npm run dev        # dev server at localhost:8080
npm run build      # production build → dist/
```
